About this portfolio

This portfolio presents five AI-assisted projects as usable product snapshots instead of a plain list. Each entry shows what the project looks like, the problem it addresses, the way the interface solves that problem, a working preview, and a path to the code.

How It Was Made

The portfolio and all included projects were built with AI assistance. The goal was not just to generate screens, but to shape each project into something understandable: clear problem statements, realistic app flows, screenshots that show the useful parts first, and preview pages that remain available from inside the portfolio.

The preview buttons open bundled versions of the projects in the same browser tab as a large overlay. That keeps the page reliable even if an outside deployment changes, moves, or disappears.

Included Projects

FinishFast

A workload and focus planner for students who need to see whether their homework plan actually fits before bedtime. It focuses on time budgets, task order, overruns, and a simple focus session.

DopamineLive

A virtual concert ticketing and merch simulator. It shows discovery, seat selection, checkout, wallet states, and event commerce in one playful flow.

gSifter

A Google Calendar sidebar concept for turning buried email event details into calendar suggestions. The preview is a mock calendar with a working sidebar simulation, fake API behavior, suggestion actions, chat rules, and settings.

Face Recall

A memory game for practicing names and faces. It treats recognition practice like a lightweight game with decks, match modes, profile states, and progress screens.

RouteUs

A carpool coordination tool for groups that need shared schedules, availability, rider details, and driver planning in one place.

Privacy And Terms

The portfolio itself does not include analytics or tracking. The preview pages are local demos bundled with the portfolio and are meant for review, presentation, and exploration.

The gSifter download is a ZIP for manual Chrome extension loading. It does not install itself automatically.
